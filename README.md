# 🏠 Marketplace de Alojamientos

Aplicación web desarrollada en **Angular** para **Inversiones LR**, orientada a la consulta y gestión básica de alojamientos temporales.

El sistema permite a los huéspedes explorar diferentes alojamientos, aplicar filtros, consultar información detallada, realizar una cotización y registrar una reserva simulada.

Esta versión corresponde a una primera implementación enfocada en el **frontend**, utilizando información almacenada en un archivo JSON y servicios de Angular para su consulta y procesamiento.

## 🛠️ Tecnologías utilizadas

- **Angular** – Framework principal para el desarrollo de la aplicación.
- **TypeScript** – Lenguaje utilizado para la lógica del proyecto.
- **Bootstrap 5** – Diseño y estilos responsive.
- **RxJS** – Manejo de datos y programación reactiva.
- **Angular Router** – Navegación entre las diferentes vistas.
- **HTML5 y CSS3** – Estructura y presentación de la interfaz.
- **Git y GitHub** – Control de versiones y almacenamiento del proyecto.
- **WebStorm** – Entorno de desarrollo utilizado.
